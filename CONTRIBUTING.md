# Contributing

1. Edit only your own folder (see [OWNERS.md](OWNERS.md)).
2. Branch name: `feature/<name>-<topic>`, for example `feature/harnoor-upload-page`.
3. Open a pull request into `main`. Do not push to `main` directly.
4. Changes to `shared/contracts/` go through Varun only.
5. Commit message format: `<lane>: <what changed>`, for example `backend: add rule delete route`.
   Lanes: `core`, `backend`, `frontend`, `docs`, `tests`, `shared`, `chore`.
