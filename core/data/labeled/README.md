# labeled

| File | What it is |
|---|---|
| `gold.json` | 40 clauses taken from the 8 sample contracts in `../samples/`. First-draft labels written by an AI assistant, not reviewed by a person. The rules in `../../rules/rules.json` were written while looking at the same contracts, so scores on this file are optimistic. |
| `contract_clause_synthetic_dataset_40_revised.xlsx` | 40 synthetic clauses (sheets `Clauses`, `Labels`, `Readme`). **The clauses were written and every label was assigned by one LLM.** It is a sanity check for the tool chain and for the rules, **not an independent evaluation set** and not a gold standard. Not legal advice. |

Split of the synthetic set (used for rule work, see `../../README.md`):

- **DEV**: ids `R01`-`R10`, `E01`-`E10`, `F01`-`F10`. Rules may be written and tuned against these.
- **HOLD-OUT**: ids `H01`-`H10`. Scored once, after the rules are frozen. A hold-out stays useful only if nobody tunes on it.

`out/` holds files generated by `core/eval/merge_labels.py` and is git-ignored.
